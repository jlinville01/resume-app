# Resume

## Setting up Locally

1. Clone the repo.
2. `cd /resume`.
3. `bundle install`.
4. Start postgresql.
5. `rake db:create`
6. `rake db:migrate`
6. `rake db:seed`
7. Navigate to `localhost:3000` to visit and view site.

**To run Unit Tests:**
rake spec OR rspec

**To run Integration Tests:**
rspec --tag integration spec/
